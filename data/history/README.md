# 과거 경매 기록 (품목 단위)

- 파일: `items-YYYY-MM.csv` 한 달에 하나. 줄 = 경매일 하루 × 품목 하나.
- 칸: 경매일, 품목, 거래량(속), 거래금액(원), 품종 수. 평균가 = 거래금액 ÷ 거래량.
- 품종·등급은 들어 있지 않습니다. 품종·등급 비교는 최근 8주 자료(data/snapshot.json)로만 합니다.
- 출처: 한국농수산식품유통공사 화훼유통정보시스템, 양재 aT 화훼공판장 절화 경매.
- 처음 자료: 시세 서버 스프레드시트 '연간집계_원자료' 탭 (2025-11-21 ~ 2026-11-20, 2026-11-20 확인).
  설(2026-02-16, 02-18)·추석(2026-09-23, 09-25) 연휴는 경매가 없어 줄이 없습니다.
