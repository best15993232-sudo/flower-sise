# 과거 경매 기록

시세 서버(구글 시트)는 최근 8주만 들고 있어서, 지나간 날을 여기에 이어 쌓습니다.
`tools/history.py` 가 시세 파일 자동 작업(snapshot.yml) 때마다 돌며 빠진 날만 더합니다. 손으로 고치지 않습니다.

- `items-YYYY-MM.csv`: 경매일 × 품목 합계. 칸: 경매일, 품목, 거래량(속), 거래금액(원), 품종 수. 평균가 = 거래금액 ÷ 거래량.
- `detail-YYYY-MM.csv`: 경매일 × 품목 × 품종 × 등급. 칸: 경매일, 품목, 품종, 등급, 평균가, 최고가, 최저가, 거래량(속), 거래금액(원).
- 집계가 끝난 본경매일만 쌓습니다. 이미 있는 날은 덮어쓰지 않습니다(가장 최근 경매일만 같은 날 고쳐진 자료 반영).
- 출처: 한국농수산식품유통공사 화훼유통정보시스템, 양재 aT 화훼공판장 절화 본경매.
